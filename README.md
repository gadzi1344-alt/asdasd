# PearWallet 2.0 — масштабный кошелёк

Полноценный multi-user кошелёк с серверным хранением, доменами `.pear`, маркетом, стейкингом и переводами.  
**Готов к деплою на Render** одной кнопкой.

## Возможности

| Функция | Описание |
|---------|----------|
| **GRAM + PearStars** | Основная валюта и звёзды (1 GRAM = 100 ★) |
| **Переводы** | Реальные переводы между любыми адресами |
| **Обмен** | GRAM ↔ Stars без комиссии |
| **Стейкинг** | Демо-стейкинг GRAM |
| **Домены .pear** | Покупка нового домена за **10 000 ★** |
| **Маркет доменов** | Можно выставлять и покупать чужие домены |
| **Маркет** | Юзернеймы, номера, подарки |
| **Коллекция** | Все купленные предметы и домены |
| **История** | Полная история операций |
| **Faucet** | +1000 GRAM для демо |
| **Статистика** | Количество юзеров, доменов, переводов |

## Деплой на Render (рекомендуется)

1. Залей папку `pearwallet` на **GitHub**
2. Зайди на [render.com](https://render.com) → **New → Web Service**
3. Подключи репозиторий
4. Настройки:
   - **Name**: `pearwallet` (или любое)
   - **Runtime**: `Node`
   - **Build Command**: оставь пустым
   - **Start Command**: `node server.js`
   - **Plan**: Free
5. Нажми **Create Web Service**

После деплоя будет ссылка вида:
`https://pearwallet-xxxx.onrender.com`

> На бесплатном тарифе сервис засыпает через ~15 минут бездействия.  
> Первый запрос после сна может занять 30–60 секунд.

Файл `render.yaml` уже лежит в проекте — Render может подхватить его автоматически.

## Токен бота

Токен хранится **только** в переменной окружения `BOT_TOKEN` (локально — в файле `.env`, он в `.gitignore` и в репозиторий не попадает). На Render: Environment → Add → `BOT_TOKEN`.

## Подключение к настоящему Telegram

1. Залей на Render, в Environment добавь `BOT_TOKEN` (адрес `BOT_API_URL=https://api.telegram.org` уже стоит). Render сам подставляет `RENDER_EXTERNAL_URL`, и при старте сервер сам ставит вебхук и кнопку меню бота.
2. Открой своего бота в Telegram, нажми `/start` → «Открыть кошелёк».
3. Проверка: `https://ТВОЙ-САЙТ/api/health` → `"botConfigured": true`. Диагностика API: `node check.js`.

**Что настоящее:** вход по подписи Telegram, пополнение в Telegram Stars (инвойс XTR), возврат Stars по платежу.
**Что внутреннее:** GRAM, стейкинг, домены `.pear`, маркет — это записи в базе PearWallet, в Telegram такой валюты нет.
Получатель перевода должен хоть раз открыть кошелёк. `DEMO=1` включает тестовый режим (фейковые бонусы, faucet, вход без Telegram).

## Локальный запуск

```bash
node server.js
```

Открой http://localhost:3000

## Покупка домена

1. Главный экран → кнопка **Домен** (или Маркет → Домены)
2. Введи имя (например `myname`)
3. Система проверит, свободен ли `myname.pear`
4. Нажми «Купить за 10 000 ★»
5. Домен появится в **Коллекции** и станет основным отображаемым адресом

## API (основные эндпоинты)

- `GET  /api/health` — статус + статистика
- `GET  /api/user/:address` — баланс и имущество
- `GET  /api/history/:address` — история
- `POST /api/send` — перевод
- `POST /api/swap` — обмен
- `POST /api/stake` / `/api/unstake`
- `POST /api/faucet`
- `GET  /api/domain/check?name=` — проверка домена
- `POST /api/domain/buy` — купить новый домен (10k ★)
- `POST /api/domain/list` — выставить домен на продажу
- `POST /api/domain/buy-listing` — купить домен с маркета
- `GET  /api/market?t=u|n|g|d` — лоты маркета
- `GET  /api/stats` — глобальная статистика

## Важно про данные на Render

На free-плане файловая система **эфемерная** — при перезапуске сервиса `data/db.json` может сброситься.  
Для продакшена позже можно подключить PostgreSQL / Redis / внешнее хранилище.  
Для демо и тестов текущего решения вполне достаточно.
